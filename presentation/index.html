Lookout

The first alert tool built to notify you less.

A watch → judge → act agent that remembers what it already told you.

The problem

Alert fatigue is the default.

Every tool notifies you more

  • Google Alerts, RSS, "track this search"
  • Re-fire on every match, every duplicate, every reword
  • The same item, slightly reworded, pings you again

So you stop listening

  • The signal drowns in noise
  • You mute the channel — and miss the one that mattered
  • More alerts ≠ more signal
You don't need to see more. You need to miss less.

The solution

Lookout is a suppression engine.

You describe what you care about in plain English. Before Lookout ever pings you, it asks two questions:

1 · Have I shown you this already?

Semantic duplicates are checked against everything it has ever surfaced — stored as vectors in Redis.

2 · Does it actually matter?

Relevance is judged by Claude against a spec compiled from your ask, plus a learned per-watch threshold.

It only speaks when both clear the bar — and gets quieter the longer it runs.

How it works — end to end

Watch → suppress the noise → surface only what's new and relevant → notify or act.
